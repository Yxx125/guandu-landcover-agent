# 官渡区系统查询能力与验收矩阵（2026-09-27）

本表按当前代码列出**有明确执行路径**的查询。它不是“任意中文问题均可回答”的承诺。数值取自 CLCD 年度面积、起止年像元转移矩阵、变化斑块统计或 Neo4j 年度关系；模型负责规划或受证据约束的解释，不负责生成统计数值。街道范围已从项目范围移除。

| 类型 | 必需参数 / 典型问法 | 执行路径和真实数据 | 返回地图 / 图表 | 成功、歧义及故障口径 |
|---|---|---|---|---|
| 单年面积及占比 | 年份；可选地类 | 单工具 Agent 或统计规划器；CLCD 年度面积表 | 单年地图；柱状图、饼图；年度图谱 | 不给年份须要求补充；模型故障时不能虚构面积 |
| 两年面积比较 | 起止年；可选地类 | `compare_years` / `/api/stats/compare`，两个年度面积表 | 区间内年度地图；对比柱图、饼图 | “净变化”=结束年减起始年，不等于总转出 |
| 单/多类逐年趋势 | 起止年及地类 | 年度面积序列 `/api/stats/timeseries` | 全部年份地图；柱图、折线图，无饼图 | 多类系列各自独立；未给年份可按全时段意图处理 |
| 逐年净增减 | 起止年、单个地类 | 年度面积的相邻年份差 `/api/stats/net-change` | 全部年份地图；正负柱图、折线图 | 不代表转移矩阵的转入／转出总量 |
| 起止年转移矩阵 | 两个不同年份；可选方向 A→B | 同网格 CLCD 两期像元叠置，81 格矩阵 | 全部年份地图、变化高亮；桑基/矩阵和流向柱图 | 绝不可与逐年转移量累计混用 |
| 变化区域与斑块阈值 | 两年；可选地类及斑块面积 km² | 像元变化和八邻接斑块统计 | 年度地图、变化高亮；转入转出图表 | “斑块数”与“斑块面积”是两个量；阈值不能超过接口允许范围 |
| 两个区间同一指标比较 | 四个年份，同一地类／同一转移方向 | 对每个区间分别计算起止年矩阵 | 两个区间的并排柱图；地图显示年份合集 | 起始年早于结束年；不按相邻年求和 |
| 同一区间两方向比较 | 两年，两个明确的 A→B、C→D | 同一矩阵两个非对角格 `flow_compare` | 区间地图；两根并排柱图 | “还是／哪个更大”等问法；若方向缺失须澄清 |
| 两区间两方向比较 | 四年，两方向分别紧跟各自区间 | `agent_query_router._compare_two_period_flows` 分别执行两期矩阵 | 年份合集地图、区间与方向并列柱图；禁用误导性的合集高亮 | 两方向不能共用第一个方向；解析不明确时拒绝，不能猜 |
| 非连续指定年份面积排名 | 至少三年，单个地类，问哪一年最多/最少 | 对每个所列年份读取年度 CLCD 面积表 | 覆盖年份地图；每个年份一根柱；无跨期转移高亮 | “某年建设用地最多”比较各年的存量面积，不调用转移矩阵；多地类须澄清 |
| 转移去向排名 / 极值 | 两年 A 转成哪类；或逐年 A→B 的极值 | 起止年矩阵；逐年极值使用 Neo4j 相邻年关系 | 对应区间地图、转移图 | 逐年极值只表示相邻年流量，不能替代长期起止年矩阵 |
| 点位历史 | 经度、纬度、起止年 | 逐年原始 CLCD 栅格点位查询 | 地图点击弹窗逐年地类 | 区外或无数据点须明确标注 |
| 知识图谱和资料解释 | 可选年份、地类和事实性问题 | Neo4j 路径 + Chroma 文档片段；确定性统计结论在前，模型仅补解释 | 回答展示证据来源；地图按可解析统计条件联动 | 两跳类别关系不代表同一像元轨迹；文档不可凭空证明因果 |
| 土地覆盖概念说明 | 无年份，如“面积净变化是什么意思” | 已校验定义；不读取面积数据 | 只更新答案，不改变地图和图表 | 概念定义不应伪装成某个具体年份的统计 |

## 接口与显示的边界

- 自然语言入口：`POST /api/agent-full/ask`。同一问题可能走 Agent、统计规划器或可校验的确定性专用路径；返回的 `generation_mode` 和 `tool_trace` 表示实际路径，不能一律称为 Function Calling。
- 地图时间段查询显示区间内所有年度图；区间对比图表的两个柱必须同时写出各自年份及地类方向。跨两个独立区间时不显示“年份合集”的单一变化高亮，因为它不是任一被问的转移量。
- 查询参数缺失、跨范围、区间倒置、方向无法唯一配对时应返回 400/422 并说明缺项；模型或服务 503 时只允许对已经明确识别的条件使用确定性路径，其余问题明确报不可用。
- 测试分层：`10_acceptance.py` 验证数据与多工具调用；`11_evidence_answer_acceptance.py` 验证一次解释问答；`12_query_regression.py` 验证组合问法与歧义。三者通过仍不代表任意自由问法、所有地图瓦片及论文来源逐句得到验证。
